# MY-Rewind 对话回退

把对话撤回到任意一条历史消息：被撤回的内容从模型上下文中隐藏（日志仍完整保留在磁盘上，可审计），被撤回消息的文本和图片放回输入框草稿，方便改一改重新发送。

## 功能（v1）

1. **消息「回退」按钮**：鼠标悬停自己发过的消息 → 操作区出现「↩ 回退」→ 确认卡片 → 撤回该消息及之后全部内容。
2. **排队消息「撤回」**：agent 运行中排队的 steering 消息带「撤回」按钮，一键移除（连同其后排队项），文本放回输入框。
3. **斜杠命令**：`/rewind`、`/undo`（= 回退最近一条）；`/rewind @<seq>` 精确指定；输入命令后弹出消息选择器（含时间与预览）。
4. **回退后回填**：被撤回消息的文本自动放回输入框；消息里的图片重新进草稿附件。
5. **重叠修复**：确认卡片使用与原生菜单一致的 `--dsw-specific-menu` + `backdrop-filter`，不再与背景穿透。

## 机制说明

回退 = 往会话日志**追加**一条 surface fold 标记（与官方 `/compact` 同套机制），日志只增不改。刷新/重开会话后，已回退的区间自动恢复隐藏（兼容旧 dsh-rewind-plugin 会话的隐藏状态，并修复了原版裸 `/rewind` 刷新后隐藏丢失的缺陷）。

**v1 不含**：文件快照与还原（原插件的 both 模式会在 v2 提供；当前选择 both 会明确报错且不做任何改动）。

## 安装

```
dsh plugin --profile desktop add "D:\OneDrive\AI Agent\DSH-使用顾问\plugins\my-rewind"
```

或在 DSH 内由助手执行 `plugin_manager install_bundle` 指向本目录。改代码后需 remove + install（host 半边有 ESM 缓存）。

## 与原 dsh-rewind-plugin 的关系

命令名（rewind/undo/rewind-plugin）与隐藏识别规则保持一致，旧会话的隐藏状态可无缝重建。两个插件**不要同时启用**（命令名冲突时 my-rewind 会跳过注册并在日志告警，按钮与选择器将不可用）。建议：先禁用原插件，再启用本插件。
