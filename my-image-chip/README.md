# MY-Image-Chip 图片气泡

粘贴或拖入图片时，在输入框光标处插入**编号气泡**（🖼 图片N·文件名），说明文字直接写在气泡旁边——
图片和文字按编号一起发给模型，不用再说"第一张图""第二张图"。

## 功能

1. **贴图即插气泡**
   - `Ctrl+V` 粘贴截图、或把图片文件拖进窗口：原生附件管线照常收图，
     同时在草稿光标处插入对应编号气泡；气泡标签 = `🖼 图片N·文件名`
     （长文件名中间省略，不会占满输入框）；
   - 气泡后自动补一个空格，接着敲说明文字即可；说明就是普通文本，位置随便放；
   - 一批多图：每张图各得一个编号气泡。
2. **原生图片栏不再重复显示图片**：气泡已经承担了"定位 + 预览"职责，
   顶部图片栏里的图片项会被隐藏（文件类附件的卡片照常显示）。
3. **悬停看大图**：鼠标悬停气泡弹出图片预览 + 完整文件名（预览走内存对象 URL，不占磁盘）。
4. **删气泡 = 删图**：删掉气泡后约 2 秒，对应图片附件自动移出草稿
   （2 秒是撤销宽限期，`Ctrl+Z` 找回气泡则不会删图）。
5. **拖动换位**：按住气泡拖动可把它挪到草稿里任何位置（幻影跟随 + 落点光标条），
   编号不随位置变——编号就是图片与文字的绑定键，所以不需要重排附件。

发送时模型收到的是：若干张图片（按附件顺序）+ 文本里内联的 `[图片N]` 标记，
`[图片1]` 即第 1 张图，以此类推。

## 使用约定

- **编号按贴入顺序分配**（每会话递增，删了不复用）。只要一直用气泡管理图片，
  编号始终等于附件顺序。
- **删图的正规方式 = 删气泡**。文件类附件（非图片）仍在顶部附件栏管理。
- 用输入框的**上传按钮**选的图片不会生成气泡（拿不到文件做预览），仍走原生附件。
- 气泡预览在页面刷新后失效（内存 URL 已释放），气泡与图片本身不受影响。
- 图片栏隐藏用的是宿主 CSS 类名，DSH 大版本升级后若失效，最坏结果只是图片栏重新显示。

## 实现要点

- **零拦截观察**：paste/drop 监听挂在 document **冒泡**阶段，原生收图（Lexical PASTE_COMMAND /
  attachment 插件的 document drop）总在更早起跑；本插件事后对比
  `shell.snapshot.attachmentIds` 与基线的差集找出新附件，再与事件里的 `File`
  按下标配对（原生 `createDrafts` 保序）取预览 URL 与文件名。数量对不上（被宿主
  数量/大小限制拦过）时整批放弃气泡、toast 说明，附件本身不受影响。
- 气泡 = `inputTriggers.registerSource` 注册的引用源（`codec.serialize` 把气泡展开成
  `[图片N]` 标记发给模型）+ `conversation.input.shell(sessionId).insertReference` 落到光标处；
  失败依次降级 `slash/input-insert-reference` 事件 → `insertText` 纯文本标记。
- **删除同步**：`editor.registerUpdateListener` 里纯内存遍历 `_nodeMap` 收集存活的
  本插件引用 id（不读 DOM、不算布局，成本可忽略），孤儿附件 2 秒后 `removeAttachment`。
- 悬停/拖动全部 document 级事件委托 + 指针式拖动（同 MY-Quote v1.1.2 验证过的机制）：
  对宿主 DOM 零写入、不用 MutationObserver，不会有布线延迟或输入框抖动。
- 主题：全部走 `--dsw-alias-*` token 跟随深浅色；tooltip/toast 文字色固定
  `--dsw-static-neutral-bluish-00`。

## 卸载

在 DSH 插件管理页移除本 Bundle（或在 `plugins/` 目录删除本目录后重新同步）。
已插入的气泡会随引用源注销而失效，草稿里的 `[图片N]` 纯文本不受影响。
